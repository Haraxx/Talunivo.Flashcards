# Vocabulary revision 2

- 50 existing package IDs retained, each package raised from version 1 to 2.
- 426 vocabulary cards, up from 400 sentence/phrase cards. Grouped lists of numbers, days and related nouns have separate cards.
- Individual words, lexical phrases and short fixed expressions form the visible vocabulary. Original sentences and dialogue lines appear only as bilingual examples.
- Every card uses format version 2 and explicitly declares `isVocabulary: true`.
- Card IDs retain their original editorial position where possible; additional entries use suffixed IDs. Review identity remains the expression/translation pair, not the card position.
- Topic labels remain the existing thematic groupings. Topic search may match parts of a label; for example `Zahlen` also matches `Bezahlen`.
- This collection has been checked with Talunivo's import parser and checksum/catalog validation. Native-speaker editorial review is still useful, particularly for contextual and regional usage.

Install Talunivo 1.3 or newer before importing this revision. Check the change preview, including replacements and removals, before confirming. Existing sentence learning progress remains stored in history and is not treated as proof of knowing newly extracted words.

The public app catalog uses this repository's `main` branch. Downloads remain previews until the user explicitly confirms each package update in Talunivo 1.3 or newer.
